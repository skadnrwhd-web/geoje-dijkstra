# SEOUL ESCAPE: Dijkstra vs A*

서울을 모티브로 한 **가상 도로망**에서 다익스트라와 A* 알고리즘이 목적지까지 경주하는 브라우저 게임입니다.
같은 경주를 **YouTube Shorts / Instagram Reels용 세로 영상(1080×1920, 30fps, MP4)**으로 자동 제작할 수 있습니다.

지도는 두 가지입니다.
- **가상 서울** (기본): 서울의 구조(한강, 다리, 구 이름)를 흉내 낸 자체 생성 지도. 인터넷 없이 동작.
- **실제 서울 (OSM)**: OpenStreetMap의 실제 서울 도로망(약 1만 9천 개 교차로, 일방통행 반영). 지도 데이터 © OpenStreetMap contributors (ODbL 1.0).

화면과 영상에 나오는 탐색 노드 수·경로 길이·계산 시간은 모두 **실제로 계산한 값**입니다.

---

## 1. 준비물 (한 번만 설치)

| 프로그램 | 용도 | 확인 명령어 | 설치 |
|---|---|---|---|
| **Node.js 18 이상** | 게임 서버 실행 | `node -v` | https://nodejs.org (LTS 버전) |
| **FFmpeg** | MP4 영상 만들기 | `ffmpeg -version` | Windows: `winget install Gyan.FFmpeg` / Mac: `brew install ffmpeg` |
| **Chrome** | 게임 화면 | — | https://www.google.com/chrome |

- 추가로 설치할 npm 패키지는 **없습니다** (`npm install` 불필요).
- FFmpeg가 없어도 게임은 됩니다. 이때 "영상 만들기"는 브라우저 녹화(WebM 또는 Chrome이 지원하면 MP4)로 대신 저장합니다.
- FFmpeg를 설치한 뒤에는 터미널(명령 창)을 **새로 열어야** 인식됩니다.

## 2. 실행

터미널에서 이 폴더(`seoul-algorithm-battle`)로 이동한 뒤:

```bash
npm start
```

화면에 `Chrome에서 열기: http://localhost:8765` 가 나오면 Chrome 주소창에 아래 주소를 입력합니다.

```
http://localhost:8765
```

종료는 터미널 창에서 `Ctrl + C`.

> `index.html`을 더블클릭해서 열면 동작하지 않습니다. 반드시 `npm start`로 서버를 켠 뒤 위 주소로 접속하세요.
> 8765 포트가 이미 쓰이고 있다면: Windows PowerShell `$env:PORT=8800; npm start`, Mac/Linux `PORT=8800 npm start`.

## 3. 게임 방법

1. 위쪽 **MISSION**에 출발지 → 목적지가 표시됩니다. 왼쪽은 **DIJKSTRA(파랑)**, 오른쪽은 **A*(초록)**.
2. **▶ 시작**을 누르면 두 알고리즘이 같은 속도(1스텝 = 노드 1개 확장)로 동시에 탐색합니다. 먼저 목적지(금색)에 닿는 쪽이 이깁니다.
3. 각 패널 아래에 **탐색 노드 수 · 경로 길이 · 실행 시간**이 나오고, 끝나면 결과 비교가 표시됩니다.

| 버튼 / 설정 | 기능 |
|---|---|
| ▶ 시작 / 다시 시작 | 경주 시작 (실행 중에는 눌리지 않음 → 중복 시작 방지) |
| ❚❚ 일시정지 / ▶ 재개 | 멈추고 이어서 재생 |
| ↺ 재시작 | 처음부터 다시 재생 |
| ⏭ 결과 보기 | 애니메이션을 건너뛰고 결과로 이동 |
| 🎬 영상 만들기 | 현재 경주를 쇼츠 영상으로 제작 |
| 지도 | 가상 서울 / 실제 서울 (OSM) 전환 |
| 경로 | 미리 정한 출발→도착 조합 선택 |
| 출발점 지정 / 목적지 지정 | 버튼을 누른 뒤 지도를 클릭하면 가장 가까운 교차로로 지정 (Esc: 취소) |
| 난이도 | 쉬움 / 보통 / 어려움 — 도로 수, 막힌 도로, 공사 구역 수가 달라짐 |
| 🚧 장애물 재배치 | 공사 구역(주황 점선 원)과 막힌 도로(빨간 X)를 새로 배치 |
| 속도 | 애니메이션 속도 0.25x ~ 4x (계산 결과에는 영향 없음) |

지도 표시: 빨강 = 출발점, 금색 = 목적지, 분홍 선 = 다리, 빨간 점선·X = 막힌 도로, 초록 원 = 산, 주황 점선 원 = 공사 구역, 흰색/노랑 굵은 선 = 최종 경로.

### 지표의 뜻
- **탐색 노드**: 알고리즘이 확장(확정)한 서로 다른 교차로 수.
- **경로 길이**: 찾은 경로의 실제 도로 비용 합계. 가상 지도에서는 "가상 km".
- **실행 시간**: 탐색 계산만 잰 시간. 너무 짧아 한 번만 재면 부정확하므로 약 60ms 동안 여러 번(보통 수백~수천 회) 반복한 **평균**입니다. 그리기·애니메이션·영상 인코딩 시간은 포함하지 않습니다. 기기와 브라우저 상태에 따라 달라지며, 차이가 작으면 "비슷함"으로 표시합니다.

## 4. 실제 서울 도로망 모드

화면의 **지도** 선택에서 "실제 서울 (OSM)"을 고르면 실제 도로망으로 경주합니다.
이 폴더에는 이미 `data/real-map.json`(2026-10-25 기준 데이터)이 들어 있어 **바로 쓸 수 있고 인터넷도 필요 없습니다.**

| 항목 | 내용 |
|---|---|
| 데이터 | OpenStreetMap (Overpass API, API 키 불필요, 한 번만 내려받음) |
| 출처 표시 | 지도 오른쪽 아래, 화면 맨 아래, 영상 하단에 "© OpenStreetMap contributors (ODbL 1.0)" 자동 표시 |
| 범위 | 서울 전역 (위도 37.425~37.70, 경도 126.79~127.185, 일부 경기 지역 포함) |
| 도로 | 고속도로·도시고속도로·간선·보조간선·집산도로 (골목길 제외) |
| 이동 비용 | 도로를 따라간 실제 거리(km). 신호·정체·회전 제한은 반영하지 않음 |
| 일방통행 | OSM의 oneway 정보 반영 (고속도로·회전교차로 포함) |
| 난이도 | 쉬움 = 간선도로만, 보통 = +보조간선, 어려움 = +집산도로 |
| 장애물 재배치 | 일부 도로를 가상의 '통제 구간'(빨간 X)으로 막음 — **실제 교통 정보가 아님** |

지도 타일(배경 이미지)은 쓰지 않고 도로 데이터만 직접 그리므로 타일 서버 이용 정책과는 관계가 없습니다.
인터넷이 없거나 `real-map.json`이 없으면 "실제 서울 (OSM) — 데이터 없음"으로 표시되고 가상 지도로 계속 동작합니다.

### 최신 데이터로 다시 받기
```bash
npm run fetch-map
```
- 공개 Overpass 서버에서 약 19MB를 1~3분 동안 내려받아 `data/osm-cache/`에 보관하고, 게임용 `data/real-map.json`(약 2.5MB)으로 변환합니다.
- 공용 서버이므로 자주 반복 실행하지 마세요. 이미 받은 원본으로 다시 변환만 하려면 `npm run fetch-map -- --offline`.
- 범위·도로 등급·장소·경로 목록은 `data/real-map-config.json`에서 바꿉니다 (장소는 위도 `lat`, 경도 `lon`). 바꾼 뒤 위 명령을 다시 실행하세요.
- 직접 받은 Overpass JSON 파일이 있으면: `npm run fetch-map -- --input 파일경로.json`

## 5. 쇼츠 영상 만들기

1. 원하는 경로·난이도로 맞춘 뒤 **🎬 영상 만들기**를 누릅니다.
2. 진행률이 표시됩니다 (30초 영상 기준 약 40~60초 소요). 중간에 **취소**할 수 있습니다.
3. 완료되면 미리보기와 함께 **파일 이름과 저장 위치**가 표시됩니다.

- 저장 위치: `seoul-algorithm-battle/output/`
- 파일 이름: `seoul_escape_YYYYMMDD_HHMMSS.mp4`
- 형식: H.264 MP4, 1080×1920, 30fps, yuv420p (YouTube Shorts·Instagram Reels 업로드용)

영상 구성 (기본값):

| 시간 | 내용 |
|---|---|
| 0~3초 | 제목, DIJKSTRA VS A*, GO! |
| 3~22초 | 두 알고리즘 동시 탐색 (위: 다익스트라, 아래: A*) |
| 22~27초 | 목적지 도착과 최종 경로 |
| 27~30초 | 탐색 노드·경로 길이·계산 시간 비교 |

영상은 프레임 번호만으로 화면이 결정되는 방식으로 한 장씩 그려서 FFmpeg로 인코딩합니다. 그래서 화면 녹화와 달리 프레임이 빠지지 않고, 영상을 만드는 동안 게임을 조작해도 내용이 바뀌지 않습니다. 파일은 내 컴퓨터 안에서만 처리되며 외부 서비스로 올라가지 않습니다.

## 6. 직접 고치기 (코딩 몰라도 됩니다)

파일은 메모장이나 VS Code로 열어 수정하고, 저장한 뒤 브라우저를 **새로고침(F5)** 하면 반영됩니다.
JSON 파일은 쉼표(`,`)와 따옴표(`"`)를 지워 버리지 않도록 주의하세요. 형식이 틀리면 화면에 오류 안내가 나옵니다.

### 제목·문구·영상 길이 — `data/game-settings.json`
```json
"title": "SEOUL ESCAPE",          ← 게임/영상 제목
"subtitle": "Dijkstra vs A*",     ← 부제
"video": {
  "introSeconds": 3,              ← 시작 화면 길이(초)
  "searchSeconds": 19,            ← 탐색 장면 길이(초)
  "pathSeconds": 5,               ← 경로 장면 길이(초)
  "statsSeconds": 3,              ← 결과 비교 장면 길이(초)
  "fps": 30
}
```
예: 15초 영상을 원하면 `2, 8, 3, 2`처럼 바꾸면 됩니다.
`game.defaultDifficulty`(`easy`/`normal`/`hard`)와 `game.defaultScenario`(경로 목록의 순서, 0부터)로 처음 화면을 정할 수 있습니다.

### 지도 — `data/sample-map.json`
좌표는 가로 0~24, 세로 0~15 (가상 km, 왼쪽 위가 0,0).
- `places`: 출발/도착 후보 장소 이름과 위치
- `scenarios`: 경로 선택 목록 (`start`, `goal`에 places의 `id`를 씀)
- `districts`: 지도에 표시할 구 이름과 위치
- `bridges`: 한강 다리 이름과 가로 위치
- `river.points`: 강이 지나가는 점들
- `obstacles`: 산(통과 불가 구역) 위치와 반지름 `r`
- `difficulties`: 난이도별 격자 크기(`cols`, `rows`), 막힌 도로 비율(`blockedRoadChance`), 공사 구역 수(`constructionZones`) 등
- `seed`: 바꾸면 도로 모양이 달라집니다

## 7. 테스트

```bash
npm test
```

외부 테스트 도구 없이 Node.js 기본 테스트 기능으로 실행합니다. FFmpeg가 있으면 실제로 MP4를 만들어 ffprobe로 확인합니다.

- 다익스트라·A* 결과가 별도로 구현한 기준 정답(최단 거리)과 일치 — 무작위 그래프 200개, 가상 서울 지도 3난이도 × 장애물 배치 5종 × 경로 5개
- 도달 불가 목적지, 막힌 도로 우회, 일방통행, 강은 다리로만 건너기, 같은 설정 → 같은 지도
- 탐색 노드 수 = 확장한 고유 노드 수, 경로 길이 = 실제 간선 비용 합
- 실행 시간 측정에 애니메이션이 섞이지 않음, 시작/일시정지/재개/재시작/중복 시작 방지
- 서버: 파일 노출 범위, MP4 생성(h264·yuv420p·프레임 수·길이), 오류 메시지, 취소 시 미완성 파일 삭제
- OSM 변환기: 교차로 추출, 굽은 도로 길이 합산, 일방통행(yes/-1/고속도로/회전교차로), 범위 밖 절단, 고립 도로 제거, 출처 정보
- 실제 서울 도로망: 3난이도 × 경로 5개에서 두 알고리즘의 경로 길이 일치, 경로가 통행 방향을 지킴

## 9. 문제 해결

| 증상 | 해결 |
|---|---|
| "게임을 불러오지 못했습니다" | `npm start`로 서버를 켜고 `http://localhost:8765`로 접속했는지 확인 |
| 영상이 WebM으로 저장됨 | FFmpeg 미설치. 설치 후 터미널을 새로 열고 `npm start` 다시 실행 |
| "MP4 인코딩에 실패했습니다" | 터미널 창의 오류 내용을 확인. 디스크 공간 부족 여부 확인 |
| 포트 사용 중 오류 (`EADDRINUSE`) | 다른 포트로 실행: `$env:PORT=8800; npm start` |
| 영상 제작이 느림 | Chrome 창을 앞에 둔 채로 기다리세요. 다른 탭으로 가면 브라우저가 작업 속도를 늦출 수 있습니다 |

## 10. 아직 구현하지 않은 것

- 실제 도로망의 이동 비용은 거리만 반영합니다 (제한속도·신호·실시간 교통·회전 금지 미반영).
- 골목길(residential 등)은 포함하지 않습니다. 넣으면 교차로가 수십만 개로 늘어 화면이 느려집니다.
- 배경 음악·효과음, 자막 문구 편집 화면
- 브라우저 자동 UI 테스트 (Playwright 등 미설치 — 이번에는 앱 내 브라우저로 직접 조작해 확인)
