**왜 바꿨나**: 새 파일은 설정을 한곳에서 관리하려는 목적으로 보입니다(파일 설명에 적혀 있음). 추가된 값들의 이유는 코드 주석 외에는 자료에서 확인되지 않음. Claude의 작업 설명("서울 다운로드가 끝나길 기다린다")은 이 파일 변경과 직접 관련이 없습니다.

**줄별 설명**
- `CONFIG_PATH = PROJECT_DIR / "config.json"` → 설정 파일의 위치를 프로젝트 폴더 안의 `config.json`으로 정함
- `DEFAULTS = {...}` → 모든 설정의 기본값 모음. `config.json`엔 바꾸고 싶은 값만 적어도 됨
- `"map_mode": "seoul"` → 실제 서울 도로망을 쓸지(`seoul`), 가상 격자 도시를 쓸지(`grid`) 고름
- `"start"`/`"goal"` → 출발지(광화문)와 목적지(사당역)의 이름과 위도·경도(지구상 위치 좌표)
- `"margin_km": 1.0` → 출발·도착을 감싸는 사각형에 1km 여유를 더해 지도를 받음
- `"fit_panel_aspect": True` → 화면 패널의 가로세로 비율에 맞춰 지도 영역을 넓힘
- `"network_type": "drive"` → 자동차 도로를 사용
- `"repeats": 7` → 실행 시간을 7번 재서 중앙값을 씀
- `"width": 1080, "height": 1920, "fps": 30` → 세로형 영상 크기와 초당 프레임(장면 수)
- `"style": {...}` → 배경·도로·알고리즘별 색상(`#00e5ff` 같은 색 코드)
- `def deep_merge(base, extra)` → 기본값 위에 사용자 값을 겹쳐 새 설정을 만듦(안쪽 묶음까지 합침)
- `def load_config(...)` → `config.json`이 있으면 읽고, 없으면 기본값만 사용
- `def save_config(...)` → 검사 후 설정을 파일로 저장
- `def validate(cfg)` → 흔한 실수(잘못된 모드, 이상한 좌표, 홀수 영상 크기 등)를 알기 쉬운 오류 메시지로 알림

**수정된 부분**
- `"start_frac": [0.45, 0.04]`, `"goal_frac": [0.55, 0.96]` → 격자 모드에서 출발·도착 위치를 지도 가로·세로 대비 비율(0~1)로 지정

**왜 바꿨나**: 주석상 시간 측정에서 좌표표 만드는 시간을 빼기 위함으로 보입니다("시간 측정 밖"). 그 외 이유는 자료에서 확인되지 않음.

**줄별 설명**
- `H_SAFETY = 1 - 1e-9` → 추정값을 아주 살짝 줄여 계산 오차로 과대 추정되는 것을 막음
- `class SearchResult` → 결과(경로, 비용, 확장 노드 수 등)를 담는 틀
- `def dijkstra(adj, s, t)` → 출발 s에서 도착 t까지 가까운 곳부터 탐색

- `def prepare_coords(graph)` → (새로 추가) 위경도 또는 평면 좌표표를 한 번만 만들어 저장

- `c1, c2 = prepare_coords(graph)` → (수정) `make_heuristic`이 준비된 좌표표를 가져다 씀

### README.md (수정)

**한 줄 요약**: README의 앱 실행 명령어를 `streamlit run app.py`에서 `python -m streamlit run app.py`로 바꾸고, 오류가 날 때의 안내 문구와 접속 주소를 추가했습니다.

**왜 바꿨나**: README 본문에 적힌 이유는 "Streamlit 실행 파일이 PATH(컴퓨터가 프로그램을 찾아다니는 경로 목록)에 없을 때 '내부 또는 외부 명령이 아닙니다' 오류가 나기 때문"입니다. 다만 이 오류가 실제로 누구에게, 언제 났는지는 자료에서 확인되지 않음.

**줄별 설명**
- `python -m streamlit run app.py` → 기존 `streamlit run app.py` 대신 쓰는 새 명령어입니다. `python -m`은 "파이썬에게 직접 streamlit이라는 도구(모듈)를 찾아서 실행해 달라"는 뜻입니다. 그래서 `streamlit`이라는 명령어가 PATH에 등록되어 있지 않아도 파이썬만 실행된다면 앱을 켤 수 있습니다. `app.py`는 실행할 앱 파일입니다.

- `(`streamlit run app.py` 로 쳤을 때 "내부 또는 외부 명령이 아닙니다" 오류가 나면 위처럼 `python -m` 을 붙이세요. ...)` → 새로 추가된 안내 문장입니다. 옛 명령어를 쳤을 때 Windows가 "그런 명령어를 모르겠다"고 하는 오류가 나면 `python -m`을 앞에 붙이라고 알려 줍니다. 그 오류의 원인(PATH에 Streamlit 실행 파일이 없음)도 함께 적었습니다.

- `브라우저가 열리면(안 열리면 http://localhost:8501) 다음 순서로 씁니다.` → 기존 문장 "브라우저가 열리면 다음 순서로 씁니다."에 괄호 내용이 추가되었습니다. 브라우저가 자동으로 안 열리면 직접 `http://localhost:8501`을 주소창에 입력하라는 뜻입니다. `localhost`는 "지금 쓰는 내 컴퓨터 자신"을 가리키는 주소이고, `8501`은 포트(컴퓨터 안에서 프로그램마다 배정되는 출입구 번호)입니다.
